== Build

Run the application.
[source,shell]
----
gradlew run
----

Build a jlink image to `build/sdkboy`

[source,shell]
----
gradlew jlink
----

Build a zipped jlink image to `build/sdkboy.zip`

[source,shell]
----
gradlew jlinkZip
----

Build the default native installer(s) to `build/jpackage`

[source,shell]
----
gradlew jpackage
----
